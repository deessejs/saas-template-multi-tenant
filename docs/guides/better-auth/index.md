## Code Structure

```
packages/auth/src/auth.ts             — better-auth config (SINGLE SOURCE OF TRUTH)
packages/database/src/schema/auth.ts   — drizzle tables + relations (CLI-generated)
packages/email/                       — email transport + transactional templates
```

**Rule:** all better-auth configuration lives in `packages/auth/src/auth.ts`. Never inline auth config in routes or components.

## Code State (2026-07-09)

- `auth.ts`: monolithic config ~125 lines. Organization plugin active; org creation is user-driven at `/onboarding` (first-org wizard) or `/organizations/new` (additional-org flow) — no server-side auto-create.
- `schema/auth.ts`: generated by `pnpm auth:generate`. Drizzle relations defined for `experimental.joins`.
- Email verification: enabled on signup. Flow is `/signup → /verify-email → /onboarding → /home`. The proxy guard at `apps/app/proxy.ts` routes unverified users to `/verify-email`.
- Open bugs: [#9070](https://github.com/better-auth/better-auth/issues/9070) (session.create.before) — mitigated by moving org creation to the client. Remaining open items documented in `pitfalls.md`.
